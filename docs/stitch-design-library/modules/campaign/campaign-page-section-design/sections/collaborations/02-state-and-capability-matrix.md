# Collaborations state/capability matrix - future authoring requirements

**Status:** FROZEN PLACEHOLDER

The future matrix must cover:

- execution/reference capability unavailable;
- references loading, authoritative empty, populated, local error, and filtered empty;
- supplied Needs Attention, In Progress, and Completed reference states;
- safe navigation available/unavailable;
- search/filter/sort/reset behavior when supported;
- long content and missing optional reference metadata;
- mobile card and filter-sheet states.

No state in this matrix may imply Campaign ownership of Collaboration lifecycle, deliverables, dispatch, approval, payment, or posting completion.
