# Discovery state/capability matrix - future authoring requirements

**Status:** FROZEN PLACEHOLDER

The future matrix must distinguish:

- Campaign execution capability unavailable;
- provider disconnected;
- authentication failed;
- provider loading;
- provider available with authoritative empty results;
- populated results;
- filtered empty;
- local recoverable error;
- search/filter/sort busy and reset behavior;
- manual add/Find Creators/CSV capability availability;
- Creator detail and Campaign Fit available/unavailable;
- mobile filter-sheet and keyboard states.

Unavailable must never be rendered as `0 creators`. Every populated value requires Product-approved representative data.
