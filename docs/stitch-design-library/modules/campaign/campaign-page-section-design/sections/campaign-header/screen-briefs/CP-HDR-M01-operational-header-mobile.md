# CP-HDR-M01 - Operational Header mobile

## Parent and viewport

Adapt the accepted new-project `CP-HDR-01` desktop Header. Do not generate from a historical Campaign Page screen.

Physical viewport: `390 x 844`. Represent feature Content Area only with 56px AppShell Header and 64px Bottom Navigation plus safe-area reservations. Normal inner width is 358px after 16px page padding.

## Required composition

- Campaign name plus lifecycle/readiness remain visible.
- Summary is compact/disclosed or truthfully unavailable.
- Facts use a readable two-column arrangement or list.
- Primary lifecycle action stays reachable; low-frequency actions may move to overflow.
- Asset/Brief disclosure stacks with exact hierarchy.
- Campaign Details becomes a full-screen Sheet.
- Supported Share behavior remains bounded and truthful.
- Sticky actions, if justified, sit above Bottom Navigation with clearance.

## Mobile-specific review

Correct only viewport/shell clearance, overflow, tap targets, stacking, drawer-to-sheet transformation, and bounded hierarchy/copy compression. Ensure no horizontal overflow and effective 44x44px targets. Record `360px` as a later implementation stress check.

## Required output during generation

Return only screen name, screen ID, session ID when returned, screenshot resource, and concise compliance/deviation report. Do not retrieve HTML.
