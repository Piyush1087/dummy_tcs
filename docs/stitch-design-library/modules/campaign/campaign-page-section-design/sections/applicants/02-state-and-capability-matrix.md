# Applicants state/capability matrix - future authoring requirements

**Status:** FROZEN PLACEHOLDER

The future matrix must cover:

- execution capability unavailable;
- Applications loading, authoritative empty, populated, local error, and filtered empty;
- one creator/one Application and one creator/multiple Brief Applications;
- supplied Application statuses and decision capabilities;
- accept/decline or other exact Product-authorized actions, busy/error/resolved history;
- Applicant Intelligence available/unavailable only when authoritative;
- independent Collaboration reference present/absent;
- mobile decision and filter-sheet states.

Application acceptance must never imply automatic Collaboration creation.
