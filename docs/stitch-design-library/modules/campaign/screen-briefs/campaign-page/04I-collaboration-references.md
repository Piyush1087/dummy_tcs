# CP-ST-04 — Collaboration references desktop brief

Priority: P1  
Viewport: 1440×900  
Parent: Accepted CP-ST-01; preserve the accepted CP-ST-03 distinction

## Goal and state

Show one explicit existing independent Collaboration reference associated through a canonical Application. Help the Brand identify and navigate to it without making Campaign the Collaboration owner.

## Required hierarchy

1. Inherited operational Campaign shell.
2. Collaborations workspace selected deliberately.
3. Related Collaboration count.
4. Creator identity and clear `related to this Campaign` relationship.
5. Reference label/identifier and originating Application relationship where supplied.
6. Owner-provided compact status only if included in supplied authority.
7. Safe navigation to the independent Collaboration.

## Actions

Primary: `Open Collaboration` only when a route/action is supplied; otherwise the surface is read-only.  
Secondary: return to Applicants or another Campaign workspace.

## Prohibited

Creation, stage controls, approvals, commercial management, fulfillment, Deliverable review, inferred references, or language suggesting Campaign owns the Collaboration.

## Required output

Return one reference-only screen with stable identity, artifacts, lineage and deviations. No Collaboration workflow screen may be generated.
