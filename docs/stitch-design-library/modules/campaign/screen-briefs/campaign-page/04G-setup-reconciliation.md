# CP-ST-02 — Setup and reconciliation desktop brief

Priority: P0  
Viewport: 1440×900  
Parent: Accepted CP-ST-01 shell

## Goal and state

Guide a Draft or active Campaign that cannot execute safely because it has no approved Campaign Asset and no canonical Brief. The next safe task is explicit Brand Centre Asset selection, followed by Brief and Deliverables.

## Required hierarchy

1. Inherited Campaign identity/lifecycle shell.
2. Prominent Brand-facing setup/reconciliation explanation and safe consequence.
3. Readiness requirements, separate from lifecycle.
4. Explicit Asset selector with no preselected or recommended option.
5. Selected Asset confirmation and optional inspect-in-Brand-Centre action.
6. Brief creation owned by that Asset.
7. Deliverable format, quantity and publishing applicability.
8. Campaign detail on demand.

The selector may contain representative BrandProfile, Offering and BrandOffer options with understandable type labels. It must not imply that one is automatically correct.

## Actions

Primary: `Link Campaign Asset` after explicit selection. After successful linkage, the contextual primary task may become `Create Brief`.

Secondary: inspect the Brand Centre entity, return to Campaigns, disclose Campaign strategy.

## Prohibited

Asset inference/recommendation, automatic selection, ownerless Brief, invented Deliverables, technical reconciliation/legacy language, execution action while disallowed, and any change to lifecycle caused by readiness.

## Required output

Return a separate screen identity derived from CP-ST-01, all artifacts and deviations. Do not redesign the shared shell or generate another state.
