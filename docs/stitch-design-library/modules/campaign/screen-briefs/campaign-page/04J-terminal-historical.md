# CP-ST-05 — Terminal / historical Campaign desktop brief

Priority: P0  
Viewport: 1440×900  
Parent: Accepted operational desktop family

## Goal and state

Represent an ARCHIVED historical Campaign whose complete canonical reconstruction is unsafe. Help the Brand understand truthful known history without believing the Campaign can execute.

## Required hierarchy

1. Persistent read-only framing and Archived lifecycle.
2. Campaign name and known objective/timing/budget facts.
3. Bounded Asset, Brief or participation history only where truthful.
4. Clear explanations for unavailable history without technical terminology.
5. Safe return to Campaigns and historical details on demand.

No operational workspace is selected. Do not show readiness when it cannot be reconstructed safely.

## Actions

No operational primary CTA. `Back to Campaigns` is the main navigation action; historical disclosure is secondary.

## Prohibited

Lifecycle toggle, readiness claim, reconciliation CTA, Asset/Brief mutation, Application or pipeline actions, provider metrics, inferred lineage, and the words legacy, UCE, migration or canonical reconstruction in Brand-facing copy.

## Required output

Return one desktop read-only adaptation in the same visual family, with stable identity, artifacts, lineage and deviations.
