# CP-ST-R03 — Applicants, desktop

Model guidance: `GEMINI_3_FLASH`. Viewport: 1440×900. Parent: accepted corrected R01.

## Representative state

Operational Campaign with Applicants selected and a submitted canonical Application requiring a decision.

Preserve the R01 Header and Attention Layer. The left vertical selector contains Discovery, Applicants, Collaborations; Applicants is active. The right body prioritizes submitted/action-required count, creator identity, exact Brief context, Application status/evidence, then Accept and Decline actions where capability permits. Resolved Applications are subordinate/progressively disclosed.

Accepting does not create a Collaboration. An existing independent Collaboration reference may be shown as navigation only. Govern empty, one/many, resolved, busy, local error/Retry, and capability-disabled variants. Do not create pipeline stages, inferred lineage, commercial state, or Collaboration controls.
