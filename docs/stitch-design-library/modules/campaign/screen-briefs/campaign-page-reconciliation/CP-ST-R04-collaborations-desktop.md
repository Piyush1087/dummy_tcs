# CP-ST-R04 — Collaborations, desktop

Model guidance: `GEMINI_3_FLASH`. Viewport: 1440×900. Parent: accepted corrected R01/R03.

## Representative state

Operational Campaign with Collaborations selected and one explicit independent Collaboration reference.

Preserve R01 Header/Attention and the three-item vertical selector. The body answers which independent Collaborations relate to the Campaign: creator identity, explicit reference/relationship, owner-supplied summary when available, and navigation to the Collaboration domain.

This is reference-only. Govern empty, one/many, loading, and local error/Retry variants. Do not design Collaboration creation, stages, commercial/fulfillment controls, inferred lineage, or Campaign-owned lifecycle. Reporting is not a workspace.
